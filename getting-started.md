# Getting started

Four steps. The app's home page tracks the first three for you and shows a tick
against each once it can see it in your live theme.

## 1. Turn on the app embed

**Online Store → Customize → App embeds → Easy Quotes.**

The embed loads Easy Quotes on every page and carries your settings to the
storefront. **Nothing else works without it** — not the blocks, not the
snippets. If quotes look entirely absent from your storefront, check this
first.

While you're there, set **Quote link placement**: next to your cart icon, a
floating button, or nothing at all if you'd rather place the link yourself.

## 2. Create the quote page

The app can make it for you from the home page, or you can do it by hand:
create a page in **Online Store → Pages**, then add the **Quote form** block to
it in the theme editor.

The path defaults to `/pages/quote`. If you use something else, tell the app in
**Settings → Quote page path**, or the Add to quote button will send shoppers
to the wrong place.

## 3. Add the Add to quote button

**Online Store → Customize**, open a product template, and add the **Add to
quote** block near your Add to cart button.

On themes built on theme blocks — Horizon and later — you can also drop the
block inside a **product card** and it works in every grid. See
[Theme setup]({{ '/theme-setup/' | relative_url }}).

## 4. Build your form

**Easy Quotes → Forms.** A starter form exists already, with the contact and
address fields most stores want. Add your own questions, then use **Preview** to
see what shoppers get. See [The form builder]({{ '/form-builder/' | relative_url }}).

## Try it end to end

Add a product to a quote, submit the form, then look in **Shopify → Orders →
Drafts**. Your request should be there, tagged, with the answers on it.

If the draft order doesn't appear, go to
[Troubleshooting]({{ '/troubleshooting/' | relative_url }}) — that page covers
the usual causes in the order they're worth checking.

## Then what

Set where new quote requests are emailed under **Advanced features →
Notifications**, and style the button and mini quote under **Design**.

**Support** inside the app has the common questions with links straight to the
page that fixes each one, and you can reach a human at
[help@canonicalscale.com](mailto:help@canonicalscale.com).
